This directory contains two scripts to complement the "GenerateSSCorr.m" function in "main/NetworkCode".

The python script "GenerateSSCorr.py" simultaneously runs four different single-sample network approaches based on Pearson correlation (LIONESS::PCC, SSN, SWEET, BONOBO) on the input data.

The python script "run_SSN_method.py" allows the user to select one of these single-sample network approaches to run on the input data.
